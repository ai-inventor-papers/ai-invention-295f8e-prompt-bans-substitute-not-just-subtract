## Layman Summary

Tests whether copying a base language model's internal 'plan' into its instruction-tuned twin makes the tuned model write different correct algorithms again; mostly it does not, except on one task.

## Full Summary

Iteration-5 Step-1 experiment on Qwen/Qwen3-8B (rev b968826d) and Qwen/Qwen3-8B-Base (rev 49e3418f): Claim B (primary, causal), Claim D, the reverse interchange, site controls, plan-site geometry, a descriptive Claim A screen check and a novelty audit. Setup: thinking off, bf16 on an RTX 4090, 15 tasks (13 bench tasks + T1 grid path + T2 weighted shortest path), exact common-random-number coupling (B = 20; T(0) equals the twin 20/20). Base repertoire (COMMIT #1): 5 BASE-DIVERSE tasks (T03, T2, T10, T1, T14; beta 0.36-0.66), 7 INTERMEDIATE, 3 BASE-COLLAPSED; the instruct twin's default share is 0.96-1.0. Transplant T(lambda): the instruct prefill task-spec states at blocks 12-23 are set to h_instr + lambda(h_base - h_instr). Frozen-rule verdict: Claim B DISCONFIRMED (PASS 1/5, T14; condition (iii) fails on 4). T14: T(1) produces the base runner-up (heap) in 21/49 correct S2 programs vs 0/39 for the twin, with pass 0.78 -> 0.98. It beats norm-matched random (MR), cross-task base shift (XT) and pass-matched random (MRP) at Holm p <= 7e-4; in the outcome-blind N=100 extension the discordant pairs are 44:0, 35:3 and 49:0. T03: matched-norm random beats the transplant (21/50 vs 3/50 off-default; McNemar 2:20, two-sided p = 1.2e-4). T10, T2, T1: no reopening at an intact pass rate; lambda >= 0.5 breaks T2 and T1. Site controls: EARLY (blocks 0-11) moves T03 (15/50) and T10 (14/50) more than the main band; READ (read position, ||D||/||h|| ~ 1.0-1.1) breaks the output without moving algorithms; LATE is inert. Claim D DISCONFIRMED: a push along unit(D) never escapes; the isotropic push escapes T03 at alpha 2. Reverse (instruct states into the base model): raises the base model's correct-program counts and its default share among attempts on all 4 tasks, but meets the committed prediction only on T1. Claim A screen check (descriptive): beta_t vs the iteration-4 escape fraction gives Spearman 0.78 (permutation p ~ 2e-4); r_t equals the push top-1 landing on 5/5 movable tasks. D is mostly generic: cross-task cosine 0.76-0.88, split-half cosine 0.96-1.0, and 71% of hooked cells exceed 4 ban-free units at lambda = 1. Geometry: the transplanted block-27 state stays about 88-89% of the way toward the base twin, while R moves only 18-31%. Novelty: 48 correct non-catalogue programs, 0 novel after manual adjudication (the judges over-called 14). Re-derivations: 56/56 (audit/rederive.py) and 34/34 headline checks (audit/rederive_headlines.py) match; the placebos fail as required.
