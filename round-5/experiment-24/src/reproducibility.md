# Reproducing "Transplanting the base model's plan" (iteration 5, Step 1)

This file records what was actually run, in order, on 2026-10-21. Every path below is relative to this folder.

## 1. Get the artifact

This folder is one directory of a public GitHub repository:

```bash
git clone <repository-url>
cd <repository>/<this-folder>
```

The repository holds the code, the frozen inputs (`inputs/`), every labelled program (`data/`) and all results. It
does **not** hold the activation tensors (`cache/`, 6.5 GB; see `.aii/manifest.yaml`). They are regenerated by
Stage 2 below.

After step 10, the extraction test was re-run with the pipeline's judge enabled (an inline call of
`s0.extraction_test()` with `use_judge=True`). That gave agreement 0.95, against 0.725 without the judge.

**GPU time.** 1.70 GPU-hours of batch time: 10,860 HF-engine programs (+1,420 pad rows) in 1.51 h, and 3,500
vLLM programs in 0.20 h. Spend: OpenRouter USD 0.29 (cap 1.5).

**Seeds and configuration.** All are fixed in code and in `predictions/commit0.json`:

- Token uniforms: `u_stream(task, W, j)` for the instruct model and `u_stream(task, W, j, 'base')` for the base
  model. Each is a PCG64 stream seeded by sha256 of the key.
- vLLM per-request seed: `stable_seed(task, W, j, 'base') mod (2^31 - 1)`.
- MR / ISO / BMR directions: `stable_seed('iter5d2', kind, task, W, j, lambda-or-alpha)`.
- Cross-task derangement: seed 20261021.
- Bootstraps: 2,000 replicates, seed 20261021. Rarefied Hill-1: depth 25, 1,000 subsamples.
- Decoding: T = 1.0, top-p 1, no top-k, thinking off.
- Caps: 1,024 new tokens (base T1/T2: 1,536).
- Batch: B = 20, fixed (pad rows complete a batch).
- Precision: bf16 (rule: GPU ≥ 19.5 GiB).

**Determinism.** Rows are deterministic given the GPU type, precision, batch shape and library versions. The unit
tests confirm this here:

- U1: the same slot twice gives identical tokens, 20/20.
- U2: T(0) equals the twin, 10/10 on each of 2 tasks.
- U3: SET(1) reproduces the donor state exactly at block 23.

A different GPU or kernel can change individual tokens. The within-artifact contrasts do not depend on this, because
every arm shares the same engine.

## 6. Known differences from the plan

See `results/deviations.jsonl`, summarised in README.md ("Deviations"). Most relevant for reproduction:

- The GPU was an RTX 4090, not the planned A4500; both get bf16 from the precision rule.
- Base sampling, the engine check and the twin ran before COMMIT #0 was hashed.
- The top-up used vLLM.
- Stage 6 crashed once on T2 and was resumed after the `u_stream` fix.
- The power extension was added outcome-blind and is descriptive only.
