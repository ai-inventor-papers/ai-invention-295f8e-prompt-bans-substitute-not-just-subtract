The finding

Does raising the sampling temperature make a code model try a different algorithm?

Not on the tasks where it has a default. The run holds one stream of random numbers fixed per seed, a design called , and labels every program by what it does when run on hidden tests.           Where it fails

          The law misses when the decision is spread over many openings

          Which unit does the composed law fail on, and why?

          On Llama-3.1-8B's grid task every predictor fails. Llama reaches the forking tokens through many openings, so the committed law is almost the flat law, and at high temperature the programs collapse into unusable code.

          What the paper does not show

          • The headline contrast between push and temperature ran only in an 8-bit (W8A8) engine. The push alone changes the algorithm in bfloat16 at the same absolute push norm, but the paired contrast was not repeated, and on the grid task the push moved only of 20 seeds.
          • Most results come from one model, Qwen3-8B, in non-thinking mode. The composed law was tested on held-out units in two other families, below the four the preregistered claim required, so its generality is open.
          • The law is not clearly better than the flat law, a baseline that predicts no change: it wins on units (sign test p = ). Much of its accuracy reflects how little temperature moves these units.
          • The temperature null rests on 20 seeds per task, which bounds the change rate per seed below , not at zero.
          • The tasks are short, well-known problems whose solutions are probably memorised; conclusions may not carry to open-ended programs.
          • Some label gates failed their strict criteria, so those numbers are descriptive. The activation-space geometry is correlational, and the map built from names is confounded by lexical overlap between algorithm names.
          • No control the run applied to single samples produced a correct algorithm outside the known repertoire. With an evaluator selecting programs across generations, one bin-packing search yielded eight programs that its manual read classed as a new idea, and an independent replication found none.
