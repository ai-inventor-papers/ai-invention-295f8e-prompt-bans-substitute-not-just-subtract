## Full Summary

Exposure-ban experiment (Step 1b) on Qwen3-8B (bf16, thinking off, vLLM 0.11.0, revision b968826d) over the 12 frozen tasks of the exp11 algorithm-choice bench (sha256-verified copy in bench_copy/; labeller re-check reproduces every gate.json value, references 100%). For each of 33 eligible non-default algorithms Y (19 priority Y whose frozen associate differs from the default), the prompt shows up to 5 name-scrubbed correct programs of Y, then asks COPY 'Write a correct solution.', NAMED '... that does not use {Y}.' (= template W5) or UNNAMED '... uses a different algorithm from the one above.' (N = 50 per Y and arm, seeds shared across arms). Four forecast families are committed in a sha256 hash chain before any ban sample: LADDER (default), ASSOCIATE (modal frozen 'standard alternative to Y'), PROXIMITY (nearest survivor by Zhang-Shasha distance on identifier-normalised ASTs; token-distance sensitivity) and SUBTRACT-IN-CONTEXT (non-Y landing under an iterated persistent signature veto of Y's distinctive token n-gram under the copy-twin prompt, implemented as a vLLM V1 per-request logits processor; GPU smoke tests: 0/20 vetoed n-grams vs 20/20 in the copy twin, inert veto 20/20 identical, twin divergence exactly at the vetoed position 20/20). Outputs: data/samples.jsonl (one row per program, gated bench labeller: runtime + AST + blind judge), results/c1_events.jsonl (one row per (Y, NAMED/UNNAMED) event in the frozen schema with forecasts, top-1s, log scores, gate), results/c1_summary.json (frozen advance rule, Holm-corrected paired Wilcoxon tests with task-cluster bootstrap CIs, branch verdict, sensitivities, C1-exposure, placebos), results/other_reports.json (copy rates, snap-back to default, named-vs-unnamed agreement, disguise, heterogeneity, veto diagnostics, template arm), predictions/ (committed forecasts and prompts), commitments.log (COMMIT #0/#1/#2 hash chain), audit/rederive.py (independent re-derivation + placebos), figures/, and method_out.json (exp_gen_sol_out: datasets exposure_events and exposure_samples).
