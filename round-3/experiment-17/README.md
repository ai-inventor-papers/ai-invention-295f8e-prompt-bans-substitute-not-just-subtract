## Full Summary

Internal-locus experiment on Qwen3-8B (pinned b968826d, thinking off, T=1.0) asking where a prohibition such as 'Do not use Dijkstra's algorithm' lives. It covers 6 tasks: path tasks T1 (BFS default) and T2 (Dijkstra), and bench tasks T03 (full sort), T04 (naive window), T06 (hash set) and T05 (hash map). Engine: HF with FP8 W8A8 linears (16 GB RTX 2000 Ada; U7 reproduces exp8: T2 ban 2/20 Dijkstra, twin 20/20), the exp8 inverse-CDF common-random-numbers sampler with exact coupling (U1b), 7,300 labelled samples (5,500 frozen design, 1,800 exploratory), and rules hash-chained before sampling. C2d DISCONFIRMED: a leave-one-task-out prohibition direction (blocks 12-23, task-spec positions; split-half cos 0.95-0.99; aligned with held-out tasks' mean ban displacement, cos 0.29-0.86) written into the neutral twin (displacement-targeted ADD, alpha 0.5/1/2) passes on 0/5 gated tasks against 3 norm-matched random directions. It is within the random range on 5/6 tasks; on T03 it beats random but lands on a size-k heap, not the ban's quickselect. Projecting it out of the ban never restores the default (pooled delta -0.026, CI [-0.07, 0.03]). With 15 random directions (exploratory), v is at the 80th percentile on T2. C2e: no within-ban locus on any testable task (batch-1 teacher-forced states, blocks 8-28, tokens 1-8/16, 500 within-template permutations, text controls). The class is set by the template (W4 keeps the default 20/20 on bench, all 61 T1 BFS) or by tokens after 16 (T2 fork median ~29 tokens). States of identical prefixes are bit-identical. FP8 caveat: 20-row teacher-forcing batches add 4-10% row-position noise, so states were re-extracted at batch 1; the batch-20 sensitivity run gives the same verdict. C2f NOT SUPPORTED: mean-ablating L21H17/L26H21/L26H25 gives T1 delta +0.06 over layer-matched random heads (any head ablation breaks the fragile W4 ban); T2 unchanged. 0g: Qwen-Scope base SAEs pass the frozen FR_zero rule (instruct 0.989-0.994 vs base 0.991-0.993, own text, 2x2 model x text). The rule also passes on placebo input, so it is lenient. The SAEs keep only cos ~0.3 of the ban-minus-twin displacement; 5a latents never beat DiM (1/63 trivial cells).
