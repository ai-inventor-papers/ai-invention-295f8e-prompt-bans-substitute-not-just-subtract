## Full Summary

Provides full_data_out.json (exp_sel_data_out schema; 10 datasets, 61,469 examples, 96.2 MB; schema-validated and QA-passed) plus mini_data_out.json and preview_data_out.json, built by data.py (uv inline script, pinned) from sources downloaded at pinned revisions (data_sources.json; restore with restore.sh; verify with scripts/source_fingerprints.py --check). Datasets: (1) leetcodedataset: 2,869 LeetCode problems (input = problem text, output = reference solution). For the 20 bench-mapped problems, metadata_test_cases_json holds every I/O pair parsed to kwargs/expected, with case ids leetcodedataset:<qid>:<idx> and a status (ok / expected_is_error_message / unparseable); the references re-pass check() 20/20. metadata_bench_task maps 743->T02, 215->T03, 28->T04, 1->T05, 287->T06, 587->T07, 509->T08, 547/323/1971->T10, 300->T11, 56->T13, 347->T14, 435->R1, 684->R2, 210->R3, 34->R6 (1631/1514 T02 alternates; 1091 T01 related). 146 (LRU, T09) and 295 (median, T12) are absent, so their tests must be generated. (2) mercury: 440 human solutions of 20 bench-mapped problems, including T09 LRU (22) and T12 median (22), with runtime, structural markers and I/O-hack flags. (3) llm_creativity: 225 T02 find_path programs referenced as repo@commit:path with the repository's blind-judge labels mapped to T02 modes (dijkstra 132, bellman_ford_spfa 34, bidirectional 30, other 21, dial 5, a_star 2, floyd_warshall 1); no program text because the repository has no licence (fetch the code with scripts/download_all.py). (4) thealgorithms_python: 1,354 MIT implementations, 55 hand-labelled with bench task and mode, the rest usable as AST-rule negatives. (5) clrs_text: 2,910 CLRS-30 execution traces of 15 bench-mode algorithms for tracer tests. (6) humanevalplus: 164 tasks with EvalPlus tests for harness validation. (7) enamel: 164 expert-efficient references with size-levelled input generators for time-limit and stress calibration. (8) concreteness_norms: 39,954 Brysbaert words with concreteness, SUBTLEX frequency, Qwen3 token counts and Open English WordNet noun classes; 718 flagged neutral-noun candidates for neutral-twin and context-seed prompts. (9) kodcode_algorithmic: 2,767 GPT-4o test-verified solutions, 253 naming a bench mode. (10) xlcost_python: 10,622 GeeksforGeeks programs, 209 naming a bench mode. metadata_named_algorithms are regex hints, not verified labels; metadata_duplicate_of marks repeats. Known issues: LeetCode 1971 has 73 of 77 error-message outputs; two-sum has 8 cases with no solution; order-free answers need validity checkers (metadata_leetcode_answer_semantics). Not built here (left to the bench build): frozen task specs in new wording, spec-filtered hidden tests (and oracle tests for T01/T09/T12), labellers, gold sets and forecasts. Licences: Mercury and KodCode CC-BY-NC, XLCoST CC-BY-SA, the rest Apache-2.0/MIT; llm-creativity labels only. Reproduction: reproducibility.md (Python 3.12.14, 45 pinned packages in pyproject.toml); no LLM calls, $0 spend.
