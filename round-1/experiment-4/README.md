## Layman Summary

Tests whether nudging a language model's internal state toward 'brainstorm many approaches' makes it write a wider variety of correct path-finding algorithms, compared with simply asking it to.

## Full Summary

De-commitment steering screen on Qwen3-8B (thinking off) for two path-search tasks with hidden tests: T1 grid path (catalogue bfs/dfs/bidirectional_bfs/iddfs/astar/dijkstra_unit) and T2 weighted shortest path (dijkstra/bellman_ford_spfa/bidirectional_dijkstra/floyd_warshall/dial). Method: list-minus-implement difference-of-means direction d_dc (50+50 held-out frame paraphrases) at the last prompt token, layer L*=18 (held-out AUC 1.0 on all layers, d' tie-break), added as c*||h||*d_hat at R and every generated token; c swept over {0.25,0.5,1,1.5} + pre-registered bisection, c* chosen on pass rate only (T1 0.1, T2 0.25). Controls: HF c=0 hook, vLLM baseline N=200 (engine check passed), two random directions, variable-name placebo, breadth direction, cross-task transfer, enumeration prompt, modal ban and mention prompts, succession ban. Labels from sandboxed hidden tests + runtime tracer + AST rules, judge for disagreements; R0 and labeller gate pass on both tasks (2 revision rounds). RESULTS (verdict PARTIAL): T1 is 100% BFS in every arm except bans; steering never diversifies it (pass 1.00 -> 0.57 at c=0.25, still all BFS). T2: at c*=0.25 pass 0.78 vs 0.95, correct programs shift Dijkstra->Bellman-Ford (54 BF/23 D vs 7 BF/88 D), rarefied Hill-1 +0.65 [90% cluster CI 0.31, 0.97]; but random direction rand1 does almost the same (+0.59; dc-rand1 +0.07 [-0.26, 0.39]) so the gain is not direction-specific (beats rand2 and placebo). Enumeration prompt gives no diversity (T2 -0.08); the modal ban buys +0.79 at 1.5 pass points but most banned samples still use the banned algorithm. Commitment test: ban-minus-mention shifts R toward the list frame by 0.04/0.05 of the frame distance (exact permutation p 0.021/0.007; enumeration positive control 0.54/0.58). Hash-committed forecasts: on T2 the de-committed forecast scored best (log score -0.058 vs -0.219 frequency) on one informative event; T1 forecasts degenerate. Headline numbers re-derived independently (results/audit_rederivation.json); vLLM same-seed determinism failed on T1.
