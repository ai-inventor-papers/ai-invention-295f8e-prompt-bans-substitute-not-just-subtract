## Layman Summary

We asked an AI model to write path-finding code thousands of times, banned its favourite algorithm, and mapped inside the model where its choice goes; bans mostly fail and edits to its internals do not redirect it.

## Full Summary

Behavioural + activation-space screen of Qwen3-8B (bf16, thinking off, T=1.0, HF transformers generate on one NVIDIA L4; vLLM could not start) for two path-search coding tasks: T1 grid path (catalogue bfs, dfs, bidir_bfs, iddfs, astar, dijkstra_unit) and T2 weighted shortest path (dijkstra, bellman_ford_spfa, bidir_dijkstra, floyd_warshall, dial). Provides: hidden test suites (41/42 cases) and catalogue references (tasks/); a validated labeller (runtime tracer + AST rules + blind OpenRouter judge; gate kappa 0.90/0.94, runtime-vs-adjudicated 0.96/0.92); 1550 prompts with token ids (prompts/prompts.jsonl); every labelled program (data/samples_phase{A,C,D}.jsonl; method_out.json, exp_gen_sol_out, 2310 programs + 7 contest events). KEY RESULTS (descriptive, few events): baselines collapse completely (T1 200/200 BFS, T2 200/200 Dijkstra; mention:X keeps 50/50); prompt bans mostly fail (ban:bfs compliance 0.18: 62 BFS/29 DFS/9 unit-Dijkstra; ban:dijkstra 0.22: 72 Dijkstra/27 Bellman-Ford); on T1 the displaced mass lands only on BFS's geodesic neighbours on the read-position manifold (DFS 41, unit-Dijkstra 58; never A*/IDDFS/bidir at 71-95), T2 goes to the 2nd-nearest (Bellman-Ford).
