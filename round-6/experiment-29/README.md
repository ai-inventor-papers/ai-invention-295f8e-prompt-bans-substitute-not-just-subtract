## Full Summary

Decides whether iteration 4's random-push 'escapes' (fixed random directions added to Qwen3-8B's task-spec states at blocks 12-23 change the algorithm it writes) are a property of the model or of the FP8 W8A8 engine they were found in. Iteration 4's 40 directions (seeds 9101-9140), CRN slots, twin prompts, absolute unit n[l,p], fence stop and two-stage escape rule were re-run under four numerics from one bf16 snapshot: a W8A8 (native _scaled_mm), b W8A16, c W16A8 (per-token e4m3 fake quant), d bf16. One labeller version (exp22 + iteration-5 T2 re-gate) for every row. RESULTS: engine a reproduces iteration 4 BYTE FOR BYTE on this GPU (400/400 REPRO rows vs exp22, 40/40 PN rows vs exp19), so exp22's own rows serve as engine a. Escape fraction E at alpha 2 (40 directions; each engine vs its own twin): T10 a 0.725, c 0.600, d 0.650, b screen-level 0.70 (confirmation incomplete); T2 a 0.200, b 0.125, c 0.150, d 0.150. Committed literal verdict: NOT_REPRODUCED_HIGH on both tasks -- bf16 escapes on the same directions (T10 per-direction Spearman 0.96, kappa 0.83, discordance 3:0, McNemar p=0.25). FP8 adds only a small per-slot boost on T10 (CRN-paired screen slots: off-default 0.583 vs 0.532, 30:10, exact McNemar p=0.0022; none on T2), carried partly by weight rounding (b 0.556) and not by activation rounding (c 0.497). Per-sample plan noise at the matched absolute unit is also reproduced in bf16 (T10 alpha 2: a 30/50, b 27, c 22, d 25), so iteration 5's bf16 PN null (1/50) came from its different unit/direction seeds, not bf16. Diagnostics: per-token KL to bf16 <= 0.004 nats; activation rounding adds 3-13% induced perturbation; landings unchanged (DFS/BFS on T10, Bellman-Ford/SPFA on T2). Validation: CPU gates C1-C5 (escape code reproduces exp22 escape.json exactly), unit tests U1-U6, hash-chained pre-registration (COMMIT #0 + 5 amendments + final record), stdlib re-derivation and an independent raw-row audit with placebos (all match). Files: method_out.json (exp_gen_sol_out; datasets engine_pop/engine_twins/engine_pn/engine_posctrl/engine_summary with predict_a..d = 'label|pass' per CRN slot), data/raw/raw_<engine>.jsonl (every program with token ids), data/labels.jsonl, data/samples.jsonl, results/*.json (verdict, escape_by_engine, mcnemar, slot_flips, pn, repro, diagnostics, relabel_table, known_solutions, deviations), figures/.
